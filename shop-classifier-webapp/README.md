# Shop Name Classifier Web App

เว็บแอปแบบ Static สำหรับรับค่า `SHOP_NAME` จากการวางข้อมูลหรือการนำเข้า Excel แล้วจำแนกชื่อร้านตามกติกาใน `shop.xlsx` ก่อนส่งออกเป็น Excel

## วิธีใช้งาน

1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Chrome, Edge, Firefox หรือ Safari รุ่นใหม่
3. เลือกวิธีนำเข้าข้อมูล
   - **วางข้อมูล**: วางชื่อร้าน 1 รายการต่อบรรทัด หรือคัดลอกตารางจาก Excel
   - **นำเข้าไฟล์**: รองรับ `.xlsx`, `.csv`, `.tsv`, `.txt`
4. เลือก Worksheet, แถวหัวตาราง และคอลัมน์ `SHOP_NAME`
5. เลือกวิธีจับคู่ แล้วกด **ประมวลผลข้อมูล**
6. ตรวจ Preview และกด **Export Excel**

ไฟล์ `.xls` รุ่นเก่าไม่รองรับโดยตรง ให้เปิดใน Excel แล้วบันทึกใหม่เป็น `.xlsx`

## รูปแบบไฟล์กติกา

ไฟล์กติกาต้องมีหัวตารางอย่างน้อย 2 คอลัมน์:

| Result | Primary Keywords | Sub Keywords |
|---|---|---|
| Tops_daily | Tops, ท็อปส์ | เดลี่ |
| Tops | Tops, ท็อปส์ | |

หลักการจับคู่:

- `Primary Keywords`: ตรงอย่างน้อย 1 คำ
- `Sub Keywords`: ถ้ามีค่า ต้องตรงอย่างน้อย 1 คำเพิ่มเติม
- ไม่สนตัวพิมพ์เล็ก/ใหญ่ และปรับช่องว่างซ้ำก่อนจับคู่

## โหมดจับคู่

### เฉพาะที่สุด / ชื่อแบรนด์ที่ปรากฏก่อน

โหมดแนะนำสำหรับกติกาที่ซ้อนกัน โดยเลือกตามลำดับนี้:

1. กติกาที่มี `Sub Keywords` มาก่อนกติกาทั่วไป
2. Keyword ที่ปรากฏก่อนในชื่อร้าน
3. Keyword ที่ยาวกว่า
4. ลำดับแถวในไฟล์กติกา

ตัวอย่าง:

- `โลตัส โกเฟรช` → `Lotus_gofresh`
- `ห้างเทสโก้ โลตัส` → `Tesco Lotus`
- `กูรเมต์ มาร์เก็ต ... The Mall` → `Gourmet Market`
- `บิ๊กซี มินิ` → `BigC_mini`

คำย่อยที่สั้นมาก เช่น `โก`, `โก้`, `exp` จะต้องเริ่มที่ขอบเขตคำ เพื่อลดการจับผิด เช่น ไม่ตีความคำว่า `เทสโก้` เป็น `Lotus_gofresh`

### กติกาแถวแรกที่ตรงใน shop.xlsx

ตรวจจากบนลงล่างและคืนค่ากติกาแรกที่ตรง เหมาะเมื่อผู้ใช้ต้องการให้ลำดับแถวในไฟล์เป็นตัวกำหนด Priority โดยตรง

## ไฟล์ Excel ที่ส่งออก

ไฟล์ผลลัพธ์มี 3 Worksheet:

- `Result`: ข้อมูลเดิมพร้อม `SHOP_RESULT` และรายละเอียดการจับคู่
- `Summary`: สรุปจำนวนทั้งหมด จับคู่สำเร็จ ไม่พบเงื่อนไข และจำนวนแยกตาม Result
- `Rules_Used`: สำเนากติกาที่ใช้ในการประมวลผลครั้งนั้น

## ไฟล์ในโปรเจกต์

- `index.html` — หน้าเว็บหลัก
- `styles.css` — รูปแบบหน้าจอ
- `app.js` — การนำเข้า ประมวลผล Preview และ Export
- `classifier.js` — กติกาเริ่มต้นและระบบจับคู่
- `mini-xlsx.js` — ตัวอ่าน/เขียน `.xlsx` ภายในเบราว์เซอร์
- `shop.xlsx` — ไฟล์กติกาต้นฉบับ
- `sample-shop-names.txt` — ข้อมูลตัวอย่างที่ผู้ใช้ให้มา
- `sample-output.xlsx` — ผลลัพธ์ตัวอย่างที่ประมวลผลจากข้อมูลดังกล่าว
- `tests/run-tests.js` — ชุดทดสอบด้วย Node.js

## การทดสอบสำหรับนักพัฒนา

```bash
node tests/run-tests.js
```

แอปไม่มี Backend และไม่มีการส่งไฟล์ขึ้นเซิร์ฟเวอร์ ข้อมูลถูกประมวลผลในเบราว์เซอร์ของผู้ใช้
