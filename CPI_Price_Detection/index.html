Logic ที่ใช้

ถอดจาก Python เดิม โดยเน้นให้ผลลัพธ์และชื่อ Sheet สอดคล้องกัน
1
REL ไม่ตรง
คำนวณ RELN = ราคาปัจจุบัน ÷ ราคาเปรียบเทียบ × 100 และตรวจ diffREL > 0
2
ช่องคำนวณว่าง
ตรวจราคา / ราคาเปรียบเทียบ / REL ที่เป็น 0, ว่าง หรือ NaN ตามชุดเงื่อนไขเดิม
3
ราคากลาง
Map ด้วย “รหัส + ประเภทร้านค้า” แล้วหาแถวที่ราคาปัจจุบันไม่เท่าราคากลาง
4
ราคาที่สงสัย
Z-score รายการ 16 หลัก / หมวด 7 หลัก + REL + เหตุผลจากผู้บันทึก/ผู้ตรวจ
5
ตรวจตัวซ้ำ
ตรวจคู่ “รหัส + รหัสแหล่ง” ซ้ำ และแสดงทุกแถวที่เกี่ยวข้อง
