Logic ที่ใช้

ถอดจาก Python Analysic_03.ipynb แบบตรงไปตรงมา
1
REL ไม่ตรง
คำนวณ RELN = ราคาปัจจุบัน ÷ ราคาเปรียบเทียบ × 100 และตรวจ diffREL > 0 (ปัดทศนิยม 2 ตำแหน่ง)
2
ช่องคำนวณว่าง
รวม 4 เงื่อนไข (G/L checked, compare > 0, current > 0, prev > 0) และ drop duplicates keep last
3
ราคากลาง
Map ด้วย “รหัส + ประเภทร้านค้า” (ตัดร้านอื่นๆ) และกรองแถวที่ราคาปัจจุบันไม่เท่าราคากลาง
4
ราคาที่สงสัย
Z-score 16/7 หลัก > 2, เช็กร้านอื่นๆ, ราคากลาง, ข้อยกเว้นโปรโมชั่น และกรอง REL > 120 หรือ < 80
5
ตรวจตัวซ้ำ
ตรวจคู่ “รหัส + รหัสแหล่ง” ซ้ำ และแสดงทุกแถวที่เกี่ยวข้อง
