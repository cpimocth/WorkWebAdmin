คู่มือการวิเคราะห์และข้อจำกัด

นำเข้าครั้งเดียว → เลือกชุด/ปีฐาน/งวด/พื้นที่ → เลือกคำถาม → อ่านขอบเขต → ตรวจค่าที่ใช้ได้ → อ่านสูตรและข้อจำกัด → ตรวจข้อมูลต้นทาง → เก็บผลพร้อมการตั้งค่า
ค่าที่ไม่มีข้อมูลแสดง —; ค่าศูนย์เป็นค่าจริง; ข้อมูลถูกอ่านในเบราว์เซอร์; การวิเคราะห์ไม่แก้ Excel ต้นฉบับ
รุ่นนี้เพิ่ม 16 มุมวิเคราะห์จาก 7 กลุ่มสถิติของรุ่น 3 ไม่ได้ครอบคลุมสถิติทุกวิธีที่มีในโลก และไม่มีการรับรองผลลัพธ์ว่าไม่มีข้อผิดพลาด

เลือกเส้นทางให้เหมาะกับงาน

งานสรุปผู้บริหาร: ภาพรวม → ตรวจผลรวม Contribution → ความกว้าง → ความกระจุกตัว → เก็บผลในสมุด → จัดรายงาน

งานตรวจข้อมูลประจำเดือน: ความครบถ้วน → ตารางต้นทาง → Robustness → คู่ A/B → ประวัติการแทนที่ → บันทึกข้อสังเกตแยกจากตัวเลข

งานอธิบายการเปลี่ยนตามเวลา: ประวัติ → ความต่อเนื่อง → รูปแบบเดือนเดิมข้ามปี → Lag → องค์ประกอบ log-YoY โดยตรวจความครบทั้ง 4 จุดเวลา

งานสำรวจรูปแบบหลายตัวแปร: Distribution → Scatter → เปรียบเทียบรวม/ภายในกลุ่ม → PCA → K-means → ตรวจสมาชิกและแถวที่ถูกตัดเพราะค่าขาด

งานทดลองสมมติฐาน: Scenario หรือ Bootstrap → อ่านข้อสมมติ → ตั้งค่า → แยกผลทดลองจากผลต้นทาง → เก็บพร้อมคำอธิบายในสมุด

งานทำซ้ำรอบถัดไป: เปิด JSON ชุดทำงาน → เพิ่มไฟล์ใหม่ → ตรวจรายการที่ชนและประวัติการแทนที่ → ปรับงวดด้านบน → เปรียบเทียบบันทึกเดิมกับผลคำนวณใหม่

การกระจายของข้อมูล

ใช้ดู: Histogram นับจำนวนค่าภายในช่วง · Box plot แสดงควอร์ไทล์และเกณฑ์ปลาย · ECDF แสดงสัดส่วนสะสมของค่าที่ไม่เกินตำแหน่งนั้น

ค่าเฉลี่ย = Σx/n; sample SD = √[Σ(x−mean)²/(n−1)]; มัธยฐานและควอร์ไทล์ใช้การแทรกเชิงเส้นที่ตำแหน่ง (n−1)p

ข้อควรระวัง: SD นี้เป็นการกระจายของตัวแปรและแถวที่เลือก ไม่ใช่ความผันผวนราคาในเวลาเสมอไป ถ้าเลือกหลายเดือนแถวรายการเดิมจะปรากฏซ้ำตามงวด

ความสัมพันธ์

ใช้ดู: เลือกแกน X/Y ขนาดจุด สี และเส้นตรง · แสดง Pearson และ Spearman · ตรวจคู่ค่าครบ

Pearson ใช้ covariance หารด้วยส่วนกระจายทั้งสองแกน; Spearman ใช้ Pearson ของอันดับ โดยให้อันดับเฉลี่ยเมื่อค่าซ้ำ

ข้อควรระวัง: ความสัมพันธ์และ R² ไม่ยืนยันเหตุและผล ค่าคงที่หรือคู่ข้อมูลไม่พอแสดง — ไม่สร้างค่า p-value หรือช่วงนัยสำคัญ

เวลาและความผันผวน

ใช้ดู: เลือกหนึ่งรหัส เปรียบเทียบหลายพื้นที่ หรือดูค่าเฉลี่ย/SD เคลื่อนที่และผลต่างรายเดือน

Rolling statistics ต้องมีค่าครบทุกเดือนในหน้าต่าง; difference = ค่าปัจจุบัน − ค่างวดก่อนที่ติดกัน

ข้อควรระวัง: ไม่เชื่อมช่องว่างด้วยการประมาณ และไม่ใช้เดือนก่อนหน้าที่พบมาแทนเดือนตามปฏิทิน การปรับงวดแรก=100 เป็นการแสดงผลไม่ใช่เปลี่ยนปีฐานทางการ

เปลี่ยนระหว่างสองงวด

ใช้ดู: เลือก A/B แล้วดูกราฟจุดคู่ ตารางทิศทาง และแถวที่มีเฉพาะงวดใดงวดหนึ่ง

จับคู่ด้วยรหัส + พื้นที่ ภายในชุดและปีฐานเดียวกัน; delta = B−A

ข้อควรระวัง: รายการเข้าใหม่ไม่ถือว่าเพิ่มจากศูนย์ และรายการหายไม่ถือว่าราคาลดเป็นศูนย์; A/B ไม่จำเป็นต้องเป็นเดือนติดกัน

ตารางไขว้

ใช้ดู: เลือกมิติแถวและคอลัมน์ เช่น หมวด × พื้นที่ หรือ CODE7 × เดือน แล้วเลือกค่าสรุป

ค่าเฉลี่ย/มัธยฐาน/SD/ต่ำสุด/สูงสุด/จำนวน/ค่าว่าง/สัดส่วนเพิ่มลด หรือถ่วงน้ำหนัก; การรวมผลกำหนดให้ใช้ Contribution

ข้อควรระวัง: ระวังตารางรวมหลายหมวดแม่กับลูกอาจนับซ้ำ เลือกเฉพาะรายการปลายทางหรือระดับที่ไม่ซ้ำซ้อนก่อน การเฉลี่ยรายการย่อยไม่ใช่สูตร CPI ทางการ

แผนที่สินค้า

ใช้ดู: Treemap ใช้ขนาดแทนมวลที่เลือก และสีแทนค่าตัวแปร เพื่อเห็นโครงสร้างกับทิศทางร่วมกัน

พื้นที่สี่เหลี่ยมได้สัดส่วนกับน้ำหนักที่ใช้แสดง; สีอ่านตามสเกลในกราฟ

ข้อควรระวัง: แผนที่นี้ไม่ใช่แผนที่ภูมิศาสตร์ พื้นที่กล่องไม่ได้แทนจำนวนคนหรือมูลค่าตลาด ถ้าไม่มีน้ำหนักต้องอ่านคำอธิบายการแสดงผล

ความครบถ้วน

ใช้ดู: ตรวจ coverage ของตัวแปรและจำนวนแถวที่อ่านได้ แยกค่าศูนย์ออกจากค่าว่าง

Coverage = จำนวนค่าตัวเลขที่ใช้ได้ / จำนวนแถวในขอบเขต × 100

ข้อควรระวัง: ความครบถ้วนของไฟล์ที่นำเข้าไม่เท่ากับความครบถ้วนของตะกร้า CPI จริง ต้องมีทะเบียนรายการที่คาดหวังจึงจะตรวจของที่หายไปทั้งหมดได้

พจนานุกรมตัวแปรและหน่วย

Index / ดัชนี: ระดับดัชนีอ้างอิงปีฐาน ไม่ใช่ราคาบาทและไม่ใช่ค่าครองชีพรายบุคคล การเทียบต้องตรวจปีฐาน

MoM / YoY / AoA / QoQ / HoH: อัตราเปลี่ยนแปลงที่นำเข้าจากคอลัมน์ต้นทาง เว็บไม่สร้างอัตราที่ขาดขึ้นแทนโดยอัตโนมัติ รายละเอียดช่วงเฉลี่ยของ AoA/QoQ/HoH ให้ยึดนิยามของรายงานต้นทาง

Contribution: ส่วนที่มีต่ออัตรารวม หน่วยจุดร้อยละ ตามคอลัมน์วิธีเปรียบเทียบที่เลือก การเปลี่ยนจาก 1% เป็น 2% คือเพิ่ม 1 จุดร้อยละ ไม่ใช่ 1%

น้ำหนัก / สัดส่วนน้ำหนัก / สัมพัทธ์ราคา / สัมพัทธ์น้ำหนัก: อ่านเป็นคนละตัวแปรตามชื่อคอลัมน์ ไม่ถือว่าใช้แทนกันได้ ไม่มีการอนุมานความหมายคอลัมน์ที่ขาดจากค่าตัวอื่น

n / valid / missing: จำนวนแถวในขอบเขต จำนวนค่าที่ใช้ได้ และจำนวนที่ไม่ใช้เพราะขาด/ไม่เข้าเงื่อนไข ต้องอ่านตัวหารทุกครั้ง ไม่ถือว่าจำนวนแถวเท่ากับจำนวนครัวเรือนหรือแหล่งราคา

สูตรของฉัน: คำนวณจากสองคอลัมน์ด้วย + − × ÷ หรือ (A/B−1)×100 ผลเป็นตัวแปรสำหรับสำรวจ ไม่เปลี่ยนต้นฉบับ และไม่หารเมื่อ B=0

ส่วนต่างเชิงพรรณนา / สถานการณ์สมมติ / การทดลอง: เป็นสามกรอบที่ต้องแยกกัน ตัวเลขคำนวณได้ไม่ได้หมายความว่าตีความเป็น CPI ทางการ การคาดการณ์ หรือผลเชิงสาเหตุได้

คำถามที่พบบ่อยและการตรวจสอบก่อนใช้ผล

เริ่มตรงไหนเมื่อมีหลายไฟล์?

เลือก Excel/CSV หลายไฟล์หรือทั้งโฟลเดอร์พร้อมกันที่ปุ่มนำเข้าจุดเดียว จากนั้นตรวจหน้าข้อมูลนำเข้าก่อนเลือกชุด ปีฐาน งวด และพื้นที่ ข้อมูลที่นำเข้าสำเร็จใช้ร่วมกันทุกหน้า

ทำไมบางกราฟไม่เปลี่ยนตามตัวกรองทุกตัว?

บางวิธีต้องใช้ขอบเขตเฉพาะ เช่น Reconciliation ใช้ 7 หมวดหลัก ส่วนอนุกรมเวลาใช้รหัสเดียวและพื้นที่เดียว อ่านส่วน “เลือกตัวแปรและขอบเขตข้อมูล” และบรรทัดเงื่อนไขใต้กราฟ ซึ่งระบุข้อยกเว้นไว้

ทำไมตัวเลข — ไม่ใช่ 0?

— หมายถึงไม่มีค่า หรือไม่เข้าเงื่อนไขคำนวณ เช่น ตัวหารเป็นศูนย์ จำนวนค่าไม่พอ หรือเดือนขาด ส่วน 0 เป็นค่าตัวเลขจริงและเข้าตัวหารเมื่อวิธีนั้นอนุญาต

ทำไมผลรวม Contribution ไม่เท่ากับอัตราภาพรวม?

อาจเกิดจากคอลัมน์/ความครอบคลุม/การปัดเศษ/วิธีคำนวณต้นทางต่างกัน ระบบแสดงส่วนต่าง ไม่เติมกลับไปหมวดใดและไม่ประกาศว่าผิดโดยอัตโนมัติ ควรตรวจแถวต้นทางและคู่มือการคำนวณของข้อมูลชุดนั้น

ทุกชุดที่ปีฐานไม่ระบุใช้เทียบกันได้หรือไม่?

ยังยืนยันไม่ได้ ปีฐาน NA คือข้อมูลกำกับที่ขาด ไม่ใช่หลักฐานว่าปีฐานเหมือนกัน ให้แก้ข้อมูลกำกับจากเอกสารต้นทางก่อนเทียบดัชนีตามเวลาและข้ามชุด

คลิกค่าที่น่าสงสัยแล้วพบอะไร?

แถวที่รองรับการเจาะข้อมูลจะเปิดรายละเอียดรหัส ค่าตัวแปร ประวัติ และไฟล์/ชีต/แถวต้นทาง ค่าสรุปบางประเภทไม่มีแถวเดียวรองรับ ต้องอ่านตารางสมาชิกและสูตรประกอบ

ทำไมเลขรหัสต้องเป็นข้อความ?

Excel อาจสูญเสียหลักท้ายของรหัสยาวที่บันทึกเป็นตัวเลขก่อนมาถึงเว็บ โปรแกรมไม่สามารถกู้หลักที่หายไปได้เอง ควรเก็บรหัสเป็นข้อความตั้งแต่ต้นทาง

กดแสดงทั้งหมดแล้วส่งออกได้ทั้งหมดหรือไม่?

ตารางวิเคราะห์เชิงลึกส่งออกครบทุกแถวในผลนั้น แม้หน้าเว็บแบ่งหน้าเพื่ออ่านง่าย ส่วนกราฟอาจมีข้อจำกัดการแสดงที่ระบุ เช่น Heatmap ความต่อเนื่องแสดง 24 เดือนล่าสุด และจำนวนจุดขึ้นกับหน่วยความจำ

PCA หรือ K-means เป็นการจัดหมวด CPI ใหม่หรือไม่?

ไม่ใช่ เป็นการสำรวจรูปแบบของตัวแปรมาตรฐานในข้อมูลที่เลือก ผลเปลี่ยนได้เมื่อเลือกตัวแปร ขอบเขต ค่า K และ seed ต่างกัน ควรตรวจสมาชิกแต่ละกลุ่มและเหตุผลทางข้อมูลก่อนตีความ

ปิดเว็บแล้วข้อมูลจะอยู่หรือไม่?

ข้อมูลและสมุดหลักอยู่ในแท็บปัจจุบัน ให้กด “ส่งออก → เก็บชุดทำงาน” เป็น JSON ก่อนปิดหรือรีเฟรช ไฟล์นี้รวมข้อมูลจริง ผังกราฟ บันทึกผล และประวัติ จึงควรเก็บและแชร์ตามสิทธิ์องค์กร

ไฟล์ HTML สมุดต่างจาก JSON ชุดทำงานอย่างไร?

สมุด HTML เป็นผลอ่านอย่างเดียวพร้อมตาราง กราฟและคำอธิบาย ส่วน JSON ใช้เปิดกลับมาวิเคราะห์ต่อ รวมข้อมูลต้นทางและการตั้งค่า การมี hash ของข้อมูลไม่ใช่ลายเซ็นรับรองความถูกต้อง

ระบบนี้อธิบายเหตุผลที่ราคาขึ้นได้เองหรือไม่?

ตัวเลขชี้รายการ ทิศทาง ความสัมพันธ์ และขนาดผล แต่ไม่ได้พิสูจน์ต้นเหตุ เช่น นโยบาย อากาศ ต้นทุน หรือพฤติกรรมผู้ขาย ต้องมีข้อมูลเหตุการณ์หรือหลักฐานภายนอกที่สอดคล้องก่อนเขียนข้อสรุปเชิงสาเหตุ
