TPSO - ระบบรับมอบหมายงานจัดเก็บราคา (CPI)
============================================================

ไฟล์ในชุด
1) เปิดระบบ_CPI.bat      = ใช้เปิดระบบทุกครั้ง
2) server.py             = อ่าน Database_CPI.xlsx และเปิดเว็บแบบ Local Server
3) index.html            = หน้าเข้าสู่ระบบ / แสดงภารกิจ
4) Database_CPI.xlsx     = ฐานข้อมูลหลักที่แก้ไขงานได้

วิธีใช้งาน
1. เก็บไฟล์ทั้ง 4 ไฟล์ไว้ในโฟลเดอร์เดียวกัน
2. แก้ไขงานใน Database_CPI.xlsx ที่ชีท Tasks
3. บันทึกและปิด Excel (แนะนำให้ปิดก่อนโหลดข้อมูลล่าสุด)
4. ดับเบิลคลิก เปิดระบบ_CPI.bat
5. ระบบจะเปิด Browser ให้อัตโนมัติ
6. Login ด้วย Username / Password ในชีท Users
7. หากแก้ Excel ขณะเปิดระบบอยู่ ให้บันทึก Excel แล้วกด “อัปเดตงานล่าสุด”

รูปแบบคอลัมน์งานในชีท Tasks
- Task1_Name = ชื่องาน/รายละเอียด
- Task1_Link = ลิงก์ http:// หรือ https://
- Task1_Due  = วันที่กำหนดส่ง
จากนั้น Task2_Name / Task2_Link / Task2_Due ... ต่อได้ถึง Task7

ข้อสำคัญ
- ชื่อฐานข้อมูลต้องเป็น Database_CPI.xlsx
- ไม่ควรดับเบิลคลิก index.html โดยตรง ให้เปิดผ่าน เปิดระบบ_CPI.bat
- ชุดนี้ไม่ใช้ฐานข้อมูลที่ฝังใน HTML จึงไม่ค้างข้อมูลเก่า
- server.py ใช้เฉพาะ Python Standard Library ไม่ต้อง pip install เพิ่ม
